# Contributing

The plugin is plain JavaScript with no build step: `main.js`, `styles.css`, `manifest.json`.

1. Fork and clone the repo.
2. Open `sample-vault/` in Obsidian (*Open folder as vault*).
3. Edit `main.js` or `styles.css` in the repo root, then copy them into `sample-vault/.obsidian/plugins/sidebar-modes/`.
4. Run **Reload app without saving** to see the change.
5. Check syntax with `node --check main.js`.

Open an issue before large changes. Keep the interface text in English and CSS classes prefixed with `ss-`.
