# Backups

## The 3-2-1 rule
- **3** copies of the data
- **2** different types of media
- **1** copy off-site

## Backup types
| Type | Copies | Restore speed | Space |
| --- | --- | --- | --- |
| Full | everything | fast | high |
| Incremental | changes since the last backup | slow | low |
| Differential | changes since the last full backup | medium | medium |

> [!important]
> A backup you have never tried to restore is not a backup.
