# Hotkeys Cheat Sheet
### Custom hotkeys

| Keys | Action |
| --- | --- |
| `⌘ P` / `⌘ Space` | command palette |
| `⌘ T` | insert a template |

### Navigation

| Keys | Action |
| --- | --- |
| `⌘ N` | new note (goes into `Personal`) |
| `⌘ ,` | settings |
| `⌘ W` | close the current tab |
| `⌘ O` | quick switcher |
| `⌘ F` | find in the current note |
| `⌘ Click` a link | open it in a new tab |

### Writing

| Keys | Action |
| --- | --- |
| `⌘ B` | **bold** |
| `⌘ I` | *italic* |
| `⌘ K` | insert a link |
| `⌘ ↩` | tick / untick a checkbox |
| `Tab` / `⇧ Tab` | indent / un-indent a list item |
