# Markdown Cheat Sheet

| Syntax | Result |
| --- | --- |
| `**bold**` | **bold** |
| `*italic*` | *italic* |
| `==highlight==` | ==highlight== |
| `~~strike~~` | ~~strike~~ |
| `` `code` `` | `code` |
| `[[Note]]` | link to a note |
| `![[image.png]]` | embed an image |
| `- [ ] task` | checkbox |

## Headings
`# H1`, `## H2`, `### H3`

## Callouts
```
> [!note] Title
> Text
```
Types: `note`, `tip`, `warning`, `example`, `question`, `important`.

````
```python
print("hello")
````
